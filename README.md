## Descargas

Aquí se publican los programas de **Zapper AIO**, mi app personal "todo en uno" (tareas, notas, horario, hábitos, foco con plantas…) para Windows y Linux.

**Descargar la última versión:** [Releases → latest](https://github.com/euZAPUS/zapper-aio-releases/releases/latest)

- **Windows:** `…_x64-setup.exe` (instalador, recomendado) o `zapper-aio.exe` (programa suelto).
- **Linux:** `.AppImage` o `.deb`.

Una vez instalada, la app se actualiza sola.
